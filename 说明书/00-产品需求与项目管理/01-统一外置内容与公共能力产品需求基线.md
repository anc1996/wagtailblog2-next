# 统一外置内容与公共能力产品需求基线

更新：2026-10-31。状态：总体架构已获认可，本轮增补长期兼容与风险验收；全部新站实现尚未交付。源码证据见 [10 第 11 节](10-新站架构与AI团队审计报告.md#11-第二轮增量评审与风险补强)，设计见 [09](09-新网站产品与公共能力架构重建方案.md)。

## 1. 用户已确认的产品方向

建设可扩展的综合内容 CMS，复用 Django/Wagtail 原生基础；旧博客只是功能参考。新站独立数据库、资源命名空间和公共模型，不以兼容旧表或迁完旧数据作为前置。按小批次建设和验收，不删除旧数据库及媒体。

采用 Wagtail Core + 公共能力平台 + 内容类型注册 + 可选业务插件。各 Page 描述业务字段、面板、模板和需要的能力；公共评论、资源、人员、发现、搜索、编排及 AI 不依赖 BlogPage。具体页面内联模型使用具体 ParentalKey 属合理关系声明。

学习 WordPress 的稳定核心、注册、分类、区块和扩展点思想，不复制通用元数据万能表、任意发布 Hook 或在线插件热装卸。模块通过同步 Provider、受控生命周期协调和 SQL Outbox 事件协作。

## 2. 功能保留矩阵 F01～F16

以下编号保留为稳定验收索引；表中“当前”仅表示旧源码功能证据，不是新站已实现。

| ID | 需要保留的功能及用户场景 | 新站验收标准 |
|---|---|---|
| F01 | 首页、导航、页脚、站点布局；读者从首页进入栏目和详情 | 区分栏目/频道、Banner、人工精选、自动热门、最新、专题推荐六种来源；保留旧热门网格及单 Banner 行为，多条 Banner 与跨类型人工精选单独验收；链接、CTA、侧栏与缓存逐项对账 |
| F02 | 内容编辑与阅读：富文本、Vditor/Markdown、数学、代码、Mermaid、表格 | 后台编辑、草稿预览、发布、恢复后展示一致；表格标题/合并/说明、代码高亮和净化有样例 |
| F03 | 图片、封面、图片画廊 | 公共图片共享；图注、alt、排序属于各引用；初始图集与加载更多行为保留；历史引用不误删 |
| F04 | 文档、音频、视频、Embed | 原生 chooser、鉴权下载、HTML5 播放、Range 与第三方 Embed 逐项验证；不默认包含 HLS/转码 |
| F05 | 列表、筛选、分页、上一/下一篇 | Blog/Guide 和发现入口使用相同正式状态与权限规则；异步列表及空结果可操作 |

| F08 | 搜索、日期筛选、高亮、建议词、分析 | 正式内容经统一投影与权限回查；撤销/私有内容的标题摘要高亮不泄露；同一正式索引只有一个写入责任链 |

| F12 | 阅读量、阅读进度及统计 | 统一计数、去重与热门排序规则；审计旧 view_counts 与 view_count_v2，禁止未确认地相加回填 |
| F13 | 年月归档、时间线、类型/站点/语言/日期筛选 | Archive 只依赖 Discovery；全站或类型组合可分页；请求不实时扫描全部历史 |
| F14 | 作品展示、联系表单、导航设置 | Portfolio 可选共享资源/编排；联系表单保留校验、反滥用和反馈；后台权限有效 |
| F15 | Markdown/资源导入与 AI 辅助 | 导入选类型，复用资源摄取及原生草稿保存；AI 仅生成建议/草稿，不能自动绕过审核发布 |
| F16 | GuidePage 及未来内容类型 | Guide 不复制 Blog 的评论/媒体/搜索/统计/AI；首版 body 外置到 MongoDB，业务字段另行确认 |

缓存、资源加载、净化、错误反馈和无障碍属于对应功能的验收内容，不能用静态按钮替代实际行为。

## 3. 新增 CMS 与内容组织需求

| ID | 用户操作场景 | 目标验收 |
|---|---|---|
| F17 | 编辑在授权栏目创建、编辑、移动、复制、别名、删除，审核人审批和排程 | 原生 Page Tree、Draft、Revision、比较/恢复、预览、Workflow/Tasks、定时发布及对象权限保持；SQL 与外置快照一致 |
| F18 | 首页编辑手动选择 Blog/Guide/其他允许精选的 Page，拖动排序，改独立标题封面 | InlinePanel/Orderable；配置和引用随 HomePage Revision 草稿、预览、正式发布及恢复；不复制目标正文；与自动热门独立 |
| F19 | Blog 与 Guide 编辑各自的跨类型相关文章 | InlinePanel/Orderable；禁止自身及重复；保存/恢复关系；目标撤销或私有后前台过滤；保留标签自动推荐 |
| F20 | 一篇文章加入专题、系列及多个精选集合；目标撤销、转私有或删除 | 仍为一个 Page 身份与一份正文；明确父/集合各自发布、固定或跟随、失效隐藏和编辑修复占位；历史恢复不恢复目标公开资格 |
| F21 | 编辑创建页面图片轮播、正文画廊或复用精选组件 | 页面内联归父 Revision；正文 Block 归正文版本及 Manifest；版本化 Snippet 单独发布，引用策略明确；音视频轮播可后续扩展 |
| F22 | 开发者加入中立第三种 Page 或可选业务模块 | 主要改新类型的注册、字段、Panel、模板；公共服务无需添加具体类型分支；拒绝无效能力组合和不兼容版本 |
| F23 | 管理员为栏目负责人、Blog/Guide 作者、编辑、审核员、资源管理员及受限后台人员分配职责 | 原生用户/组、页面树权限、Workflow、Collection 优先；授权栏目/类型、本人草稿、独立审核、移动/复制/别名/排程/批量及直连请求逐项验收；资源权限不授予 Page 编辑权；后台与前台阅读分离 |
| F24 | 多站点/语言与 API 查询，逐步增大内容量 | 共享访问与正式状态规则；缓存隔离；声明容量场景与实测边界，不承诺亿级已经可用 |
| F25 | 运维人员升级、暂停或重新启用已被正文/历史使用的插件 | 稳定插件/Block/Codec 身份和旧 schema 可读；停入口保留兼容 reader、历史原始数据和迁移依赖；未知类型不得静默丢段后重存；重启事件按代次幂等恢复 |
| F26 | 同一媒体被公开页和私有页共享；读者直接下载或编辑预览 | 资源分类、引用上下文、直接 URL、原件/派生及预览分别授权；私有页引用公开图不使公开图自动保密；受限原件不可因公开引用永久开放；Range、签名窗口、撤销和缓存有实际证据 |

F18～F21 的选择行为允许在授权草稿中引用未发布目标；正式前台只展示当前可访问目标，缺失项给编辑修复提示。人工关系/顺序改变须发布其所有者；独立集合发布如何传播必须显式选择，不能以 chooser 可用代替验收。详细合同归 09 第 15 节。

F23 的“仅本人草稿”和“同栏目按用户组限制可建类型”需单独调查原生边界及扩展点；不能由 owner、add 权限或父子类型声明直接推定已经满足。角色与场景矩阵归 09 第 14.1.1 节。

首页所有轮播在移动端及键盘下可操作，验证焦点、暂停自动播放、减少动画偏好、图片失败、零/单/多项与目标失效；Banner/精选的编辑配置参加 HomePage Revision，热门与最新使用独立动态规则。旧模板/JS/缓存的静态事实与未来行为分别登记在 10 第 11 节。

## 4. 内容、资源与权威的硬边界

Wagtail 负责完整生命周期与发布；SQL 保存页面、关系、Revision、完整 Manifest 绑定和正式指针；Mongo 仅保存不可变外置版本；ES 可重建；Redis 非权威；MinIO 存二进制。

首版 BlogPage 的 body、intro 分别外置，GuidePage 的 body 外置，其他类型按字段声明选择。一次保存形成完整页面快照，一次原生发布统一切换正式快照；外置完整正文不重复写入 SQL Revision。原生历史比较、恢复、复制和审核不能被省略。

图片、文档、音视频属于全站公共资源。页面仅引用资源，不拥有文件；删除页面不能删除其他页面或历史仍引用的对象。原件不可覆盖，私有交付及回收须独立验证。

公共资源身份不等于公共访问资格。相同资源的公开派生物一旦合法公开，无法承诺撤回用户已下载的副本；受限原件、受限派生物及页面私有数据仍须独立保护。访问矩阵与撤销残余窗口归 09 第 5.5 节，图片首批子集归 08。

插件按展示/持久业务/核心生命周期三级管理，关闭功能开关不等于能从 `INSTALLED_APPS` 移除模型 App；本期只建立接口、兼容合同和扩展验收，不建设插件安装管理器。通用 Markdown、Mermaid、代码、表格与数学归公共编辑器层，媒体相关 Block 归 resources，不把旧 Blog 的全部职责搬入资源模块。

栏目用 Page Tree，分类/标签用 taxonomy；专题为独立页面，系列和精选集合按语义选择原生版本化管理方式。不是所有业务实体继承 Page，也不是所有 Page 必须使用 Mongo。

## 5. 本期排除与待决界面

会员套餐、付费会员、订单、支付、退款、续费、会员中心、商业计费系统不开发；仅保留原生认证/权限和简洁的未来访问授权接口。首次新库迁移前评估自定义 User。插件市场、任意 ZIP 在线安装、完整流媒体转码和历史数据搬迁另立项目。

U27～U36 已确认局域网公开访问、公开图片/附件简化交付、人工优先的混合相关文章、精选集合跟随/固定已发布版本、基础去重统计、登录评论、单中文站点和简单备份目标。仍待技术细化的内容包括资源交付实现、权限矩阵、统计去重算法、评论保留、备份一致性与恢复演练；不能把这些技术待验证写成已实现。

会员套餐、支付、订单、退款、续费、会员中心和在线插件市场仍属于本期排除。这里的商业会员订阅不影响 F09 保留的 RSS/Atom 及内容订阅能力。

## 6. 交付证据

后续必须用正式 Blog/Guide 证明资源、人员、搜索共用；用真实 Home/相关文章 InlinePanel 证明排序、草稿、预览、恢复；用中立第三种 Page 证明扩展；用原生 Workflow/排程及隔离跨存储故障验证权威；用真实后台与浏览器证明用户操作。

P1 两个 SQL 测试 Page 仅证明公共图片独立，不能折算成正式 Blog/Guide 交付。P3 外置桥接按 BR01～BR13 验证首次创建、自动保存覆盖、多字段、历史比较、审批竞态、排程、复制/别名、移动、删除和未知提交；Revision ID 本身不应被当作完整不可变快照的充分证据。

无权限页面不能从卡片、轮播、归档、搜索高亮、Feed、API 或资源 URL 泄露。文档、模型声明或测试文件存在都不是交付证据。容量目标需分阶段测量 Page Tree、Revision、Mongo、ES、归档和恢复成本。
