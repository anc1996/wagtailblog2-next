# 新站实施进度与验收台账

更新：2026-11-01。适用仓库：`wagtailblog2-next`。本台账是新站从第一天开始的正式交付记录；旧仓库的阶段状态、测试结果和完成标记不得直接迁入。

## 使用规则

每个独立开发切片必须登记任务编号、需求/ADR、负责人、实施状态、验证状态、验收状态、变更文件、测试与证据、未完成事项、阻断原因、下一步和最终验收结论。

- **实施状态**：未开始 / 进行中 / 部分完成 / 已完成。
- **验证状态**：未验证 / 静态 / E2 无外部 IO / E3 获授权隔离服务 / 浏览器或真实用户态。
- **验收状态**：未验收 / 待审查 / 已验收。只有正式方案同步且证据满足门禁时才能标记“已验收”。
- 任务受阻或部分完成必须登记，不得用“代码已写”替代验收。
- 涉及 P0 合同、身份、权限、Revision、外置内容或跨存储事务的切片，必须保留独立复核结论和未决问题。
