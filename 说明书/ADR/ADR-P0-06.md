## 应用装载合同

- 按阶段列必要 Django、Wagtail 核心/后台/用户/图片/文档及其必要搜索/站点等依赖，再加获批身份/公共 resources；Home 按阶段加入，fixtures 仅在测试配置追加。此描述不是可直接复制的最终 INSTALLED_APPS。
- 保留原生所需迁移、App 与搜索基础，不提前启动正式公共搜索投递。P1 不装旧 Blog/Portfolio/评论/AI/observability 等业务，不初始化 Mongo/ES/旧任务客户端。
- 审查包导入、models、AppConfig.ready、wagtail_hooks、signals、URL、模板顺序、static、Storage 初始化、任务发现；迁移模块隔离不能代替装载隔离。
- 根包导入不自动建立连接或导入 Celery。旧根包导入 Celery/旧配置/任务发现仅是历史源码风险，本批未观察到它产生真实连接。
- 功能开关不改变既有持久模型迁移图；测试/未来正式使用同一产品历史，禁止按环境切换不同起源迁移。

## 独立基础设施合同

全部目标须另外列真实身份、所有者、权限、现存数据和允许操作。下表只定义核对项，不给出获准连接地址或已经创建的资源名。

| 边界 | 操作前需核对 |
|---|---|
| Python/WSL | U25 分配、实际解释器/prefix、依赖锁、Windows/WSL 映射；路径存在不等于隔离 |
| MySQL | 主机/实例/库/账号权限、表及迁移历史；初始迁移目标必须获准且为空 |
| MongoDB | 集群/库/集合/环境 owner 命名空间及最小权限，拒绝覆盖旧版本与异常物理删除 |
| MinIO | endpoint、桶或有权限隔离的专属前缀、对象分类与交付策略；不能继承旧公开 ACL |
| Elasticsearch | 实例、物理索引/alias、重建目标及唯一写入者；不能与旧站争写 |
| Redis/Celery | 实例/逻辑库/ACL/键前缀、broker/vhost、队列/路由、任务名与结果前缀；只换 DB 号不证明隔离 |

旧文档的 IP、库名、桶名、systemctl 手册均不构成本轮许可；不按主机是否相同来推断生产/测试安全。新站基础设施独立不等于必须另买物理机器，是否共享实例及隔离强度需用户审定。

- 阶段化 App 白名单、生产/测试同图及后续配置实施细则；已有标准入口和包内 settings 仅记为骨架事实，不据此批准持久模型身份。
- 基础设施共享实例/独立实例政策，以及具体目标和分阶段操作授权；不得记录凭据。

## 风险与依赖

依赖 ADR-P0-01 的技术候选、ADR-P0-02/03 的名称、ADR-P0-04/05 的模型设置、[ADR-P0-07](ADR-P0-07.md) 的迁移图。风险为隐式旧 settings、启动即发现任务、导入 Storage 建连接、共享 Redis/ES 命名空间碰撞及用“test”环境名替代目标预检。

## 验证计划、停止与回退

- E1：静态核对已有/尚不存在的入口、候选名称、装载审查面与隔离清单；本轮不运行管理命令。
- E2：在获批配置/原型范围内，任何项目导入前阻断 DB（包括本地 SQLite）、网络（socket/HTTP）、Storage、任务与子进程，先证明守卫生效，再受守卫装载入口及只读检查已有图/状态。不生成或执行迁移、不连接真实服务、不开展 E3；禁止 migrate、makemigrations、collectstatic、runserver。普通 `manage.py check`/导入和迁移图工具不天然无 IO，未经守卫验证不得运行或记为 E2。
- E3：另获具体目标和操作授权后，先预检、再执行指定迁移/后台/服务验收；非空或旧迁移历史立即停止并保留，不清空/fake。
- 停止：settings 来源不明、越界 IO、旧包/旧任务装载、目标或权限不明，或任何生产语义。
- 回退检查：可撤回本人未部署配置，不改全局 Conda/环境配置、不重启服务、不清队列。已发生外部写入先查持久身份并对账，数据恢复另行批准。
