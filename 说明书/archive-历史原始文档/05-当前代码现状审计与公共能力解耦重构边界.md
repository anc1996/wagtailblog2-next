## 1. 证据等级

| 等级 | 含义 | 本文允许的表述 |

## 7. Blog 强绑定清单

当前需要后续逐项替换、但本轮不能直接删除的绑定包括：

1. `BlogPage.save()` 内直接写入 Blog Mongo 正文；
2. `BlogPage.publish()`、`unpublish()`、`delete()` 直接驱动 Blog 专属服务；
3. `BlogPublicationState` 作为 Blog 正式正文和发布代次的权威状态；
4. `mongo_content_id` 作为页面和搜索模型中的正文身份；
5. `search.signals` 以 `BlogPage` 为唯一页面生命周期 sender；
6. 搜索重建、文档构建、范围重算和建议查询直接导入 `BlogPage`；
7. 搜索投递逻辑读取 Blog 发布状态和 Blog Mongo 内容；
8. Markdown 导入会话、批次、Artifact 与 BlogPage 字段绑定；
9. Mongo 孤儿扫描和删除保护直接枚举 BlogPage、BlogPublicationState；
10. Blog 详情、Feed、缓存和任务使用 Blog 专属字段或服务；
11. 旧资源模型、旧作者模型和 Wagtail 全局资源配置仍是现有运行时基础。

这些绑定不能通过“新建一个 `resources` 或 `people` 目录”自动消失。必须分别完成位置、依赖方向、数据权威和生命周期入口的替换。

## 8. 跨存储权威边界

当前应继续遵守以下边界，直到公共协议得到实现和验证：

| 存储 | 应承载的权威 | 不应承担的职责 |
|---|---|---|
| MySQL | 页面元数据、Revision、Wagtail 发布状态、关系和 Outbox 业务事件 | 不以搜索结果反向覆盖页面权威 |
| MongoDB | 被明确声明为外置的不可变正文版本及其字段内容 | 不以 Mongo 内容直接证明页面已发布 |
| Redis | 缓存、租约、协调状态 | 不作为正文或发布状态权威 |
| Elasticsearch | 可重建的搜索投影 | 不作为页面、正文或权限的最终权威 |
| MinIO/Wagtail 文件存储 | 二进制资源及对象存储内容 | 不替代资源引用、权限和生命周期记录 |

跨存储写入必须明确事务覆盖范围、幂等身份、提交点、结果未知查询、对账、补偿和回收边界。Django `atomic()` 不能回滚已经写入 Mongo、MinIO 或 Elasticsearch 的外部副作用；异常处理不得以物理删除作为默认补偿。

## 9. 当前解耦边界

在公共协议、字段契约和回滚边界尚未确认前，第一阶段只能做低风险脱离：

- 允许新增公共接口、DTO、协议和兼容适配器；
- 允许让新页面业务代码依赖公共接口，而不是直接导入 Blog 模型；
- 允许补充契约测试、适配器测试和静态依赖检查；
- 暂不移动或删除 `Author`、`BlogImage`、`BlogDocument`；
- 暂不修改 Wagtail 全局图片/文档模型配置；
- 暂不创建物理模型迁移；
- 暂不重写 `BlogPage.save()`、`publish()`、`unpublish()`、`delete()`；
- 暂不把搜索信号切换为“所有 Page 自动进入搜索”；
- 暂不删除旧 Mongo 读写流程；
- 暂不连接生产或执行真实数据迁移、批量回填、物理删除。

## 10. 审计结论

当前项目不是“统一外置内容架构已完成但代码混乱”，而是：

1. BlogPage 专属生命周期仍然是实际运行主链路；
2. `people` 已有公共只读契约和 Blog 适配层；
3. `resources` 已有公共读取契约、Blog 适配层和部分 Markdown 图片读取；
4. `search` 已有较完整的投影基础设施，但核心生产者和正文读取仍 Blog 化；
5. `external_content`、GuidePage、统一 Manifest 和公共发布状态尚未形成运行时代码；
6. 当前应保持 `2E-1e-2 = BLOCKED-FACTS`，先冻结事实和协议，再进入最小实现切片；
7. 下一步最小切片应继续选择不涉及物理迁移、全局配置和 Blog 生命周期重写的公共接口或适配器工作。
